# CV Game VR 360

Tour 360° da loja do CV Game. Abre no celular (gira com o aparelho ou arrastando), no computador (arrastar e clicar) e em óculos VR (botão VR; olhe para o ponto verde por 1 segundo ou use o controle).

- `index.html`: a página inteira (A-Frame 1.6, cena montada em código, textos desenhados em canvas).
- `media/`: trechos reais do jogo mostrados em cada ponto e o QR da oferta CVSign.

Para editar os textos dos pontos, mude a lista `PONTOS` no começo do script.
Publicação: GitHub Pages, branch `main`, pasta raiz.
